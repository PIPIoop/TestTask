# Композиция

**Локальный конструктор редактируемых SVG-иллюстраций** из векторных объектов, предоставленных в Figma. Выберите предметы или опишите сцену, сравните три варианта, поправьте результат на холсте и скачайте SVG.

| Форматы | Иллюстрации | Цвет | Результат |
| --- | --- | --- | --- |
| 1200 × 1200 · 1200 × 630 · 800 × 1200 | 10 главных и 10 фоновых объектов, версии L/S | 3 встроенные схемы и импорт палитры | Векторный SVG с отдельными группами |

## Быстрый старт

1. [Скачайте репозиторий](https://github.com/PIPIoop/TestTask/archive/refs/heads/main.zip) и распакуйте архив.
2. Откройте **`dist/index.html`** в браузере. Сервер, сборка и установка пакетов не нужны.
3. Выберите формат, детализацию, палитру и предметы. Нажмите **«Создать 3 варианта»**.
4. Выберите кадр, при необходимости отредактируйте его и нажмите **«Скачать SVG»**.

Проект работает локально в браузере. Сохранённый проект можно скачать в JSON и позже загрузить обратно.

## Работа с композицией

- **Сборка:** можно выбрать объекты вручную или ввести заголовок, метафору либо перечисление предметов. Сервис подбирает подходящие исходные иллюстрации и предлагает три разных кадра. Кнопка **«Пересоздать»** собирает новую тройку из тех же объектов.
- **Редактор:** предмет можно перетащить, повернуть, продублировать, удалить или переставить в списке слоёв. Верхний фиолетовый маркер поворачивает выбранный предмет; нижний белый меняет масштаб всей композиции, сохраняя относительные размеры объектов. Масштаб и поворот закрепляются независимо. Кнопки ↶ и ↷, а также `Ctrl+Z` и `Ctrl+Y` отменяют и повторяют правки.
- **Цвет:** встроены лавандовая, абрикосовая и мятная схемы. Можно загрузить собственную палитру в JSON — цвета в векторных контурах заменятся автоматически.
- **Экспорт:** итоговый SVG содержит цветную подложку и отдельную группу для каждого объекта. Пунктирная рамка, маркеры и другие элементы редактора в файл не попадают.

## Как это устроено

```text
source-art/figma-sheet.svg
        │ выделение исходных контуров
        ▼
dist/figma-assets.js ──► подбор объектов ──► компоновка ──► экспорт SVG
        │                                        ▲
        └──► dist/shape-masks.js ──► оценка перекрытий
```

Исходный лист Figma экспортирован как плоский SVG. `source-art/extract.py` и `source-art/bboxes.json` выделяют из него 20 объектов и сохраняют исходные пути и `clipPath`. Для каждой иллюстрации доступны версии L и S. Объекты не пересоздаются и не превращаются в изображения.

Компоновщик использует отдельные схемы для сочетаний из референсов, а для остальных наборов рассчитывает связанную группу вокруг ведущего предмета. Он оценивает 18 кандидатов по видимости объектов, расстояниям, перекрытиям и балансу кадра, затем показывает три различающихся варианта. Маски силуэтов 32 × 32 помогают оценить пересечения; в экспорт они не попадают. Масштаб предметов внутри варианта меняется одним коэффициентом.

Подбор по описанию сопоставляет названия предметов и словарь смысловых тем. Явно названные объекты сохраняются в сцене. Если тема не распознана, интерфейс просит уточнить формулировку вместо случайного выбора.

Редактор хранит смещения и углы объектов, общий масштаб варианта, отдельные фиксаторы масштаба и поворота, копии и порядок слоёв. Эти данные входят в JSON проекта. Экспорт создаёт SVG без растровых изображений и внешних ресурсов; идентификаторы `clipPath` уникальны для каждой копии.

### Своя палитра

Файл JSON должен содержать `name` и цвета `bg`, `bg2`, `a`, `b`, `c` в формате `#RRGGBB`. Цвет `d` необязателен. Готовый образец: [`source-art/palette-example.json`](source-art/palette-example.json).

```json
{
  "name": "Синий вечер",
  "bg": "#DCE8FA",
  "bg2": "#8BA6D9",
  "a": "#546FC4",
  "b": "#F1A9A2",
  "c": "#F7DF99",
  "d": "#FFFFFF"
}
```

`bg` задаёт цвет подложки. Цвета объектов заменяются в исходных SVG-контурах; чёрные обводки и белые детали сохраняются. Фоновые иллюстрации остаются монохромными.

## Проверка

Для проверок без браузерных зависимостей нужен Node.js:

```bash
npm test
```

Команда проверяет синтаксис, наличие всех исходных объектов, форматы L/S, копирование, поворот, независимую фиксацию преобразований, палитру, сохранение проекта и структуру экспортированного SVG. Она также обновляет файлы в `examples/`.

Для проверки интерфейса установите зависимости и браузер Playwright, затем запустите отдельный набор:

```bash
npm install
npx playwright install chromium
npm run test:browser
```

## Ограничения

Подбор по описанию использует локальный словарь тем: незнакомую метафору потребуется уточнить. В насыщенной сцене с большим числом предметов автоматическое кадрирование можно поправить вручную.

## Возможное развитие с нейромодулями

Сейчас подбор объектов и оценка композиций выполняются локальными правилами. Нейромодули можно подключить как дополнительные этапы, сохранив исходные SVG и ручное редактирование:

1. **Понимание описания.** Языковая модель преобразует заголовок или метафору в список объектов из существующей библиотеки, их роли (главный или фоновый) и краткую идею сцены. Результат проверяется по допустимым идентификаторам; пользователь видит выбранные объекты и может заменить их до генерации.
2. **Оценка вариантов.** Текущий компоновщик создаёт несколько SVG-кандидатов. Модель компьютерного зрения сравнивает их превью по читаемости главного объекта, естественности перекрытий, балансу и близости к примерам из ТЗ. Она меняет порядок вариантов или запрашивает новую раскладку; в итоговый файл по-прежнему попадают исходные векторные контуры.
3. **Улучшение на примерах.** Выбранные пользователем варианты и его ручные правки можно с его согласия сохранять как набор для проверки качества. Это даст измеримый способ сравнивать новые версии компоновщика с текущей и постепенно уточнять правила или модель оценки.

Практичный порядок внедрения: сначала разметить удачные и неудачные композиции, затем добавить оценку вариантов, после этого расширить понимание свободного текста. Подключение внешнего API должно быть необязательным: базовая сборка и экспорт продолжат работать локально.
