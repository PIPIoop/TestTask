# Композиция — SVG-конструктор

Веб-сервис для сборки иллюстративных композиций из предоставленных векторных объектов Figma. Поддерживает форматы **1200 × 1200**, **1200 × 630** и **800 × 1200**, отдельно выбираемые версии иллюстраций **L** и **S**, три исходные и загружаемые цветовые схемы, ручной выбор объектов, подбор по текстовому описанию, три варианта композиции, перенос, поворот и дублирование предметов, сохранение проекта в JSON и экспорт редактируемого SVG.

## Запуск

Откройте `dist/index.html` в браузере. Установка зависимостей и сервер не требуются.

## Короткая демонстрация

1. Выберите формат, детализацию L/S и цветовую схему. Кнопка «Загрузить палитру JSON» добавляет свою палитру; образец находится в `source-art/palette-example.json`.
2. В режиме «Выбрать объекты» добавьте главные и фоновые элементы. Сервис предложит три варианта: выберите один из миниатюр или нажмите «Пересоздать» рядом с вариантами для новой серии из тех же предметов.
3. В режиме «Описать сцену» введите, например, «Рабочий стол с лампой, книгой и наушниками» и нажмите «Собрать композицию».
4. На экране компьютера холст, варианты и панели «Слои композиции» и «Точная настройка» помещаются в рабочей области по высоте окна. Нажмите на предмет на холсте или на его название в списке слоёв. Перетащите его мышью или пальцем. Нижний белый маркер на рамке и ползунок равномерно масштабируют всю композицию, сохраняя относительные размеры предметов; верхний фиолетовый маркер поворачивает выбранный предмет. Две независимые кнопки «Масштаб» и «Поворот» закрепляют соответствующее преобразование: можно заблокировать одно и продолжить менять другое. Угол также можно ввести числом. Перетащите карточку слоя в списке, чтобы изменить наложение: слева слои ниже, справа выше. Кнопки «Ниже» и «Выше» перемещают выбранный предмет на один слой. Каждая из трёх композиций хранит свои правки.
5. Нажмите «Скачать SVG». Откройте файл в Figma или другом векторном редакторе: фон и каждый объект находятся в отдельных группах. Рамка выбора и маркер в экспорт не попадают.
6. «Сохранить проект» скачивает JSON и сохраняет текущее состояние в браузере. «Загрузить проект» восстанавливает его из JSON.

## Архитектура

- `dist/figma-assets.js`: 40 выделенных векторных иллюстраций: по 10 главных и 10 фоновых для двух размеров.
- `dist/shape-masks.js`: компактные маски видимых контуров и основных цветных частей каждого объекта для оценки перекрытий.
- `dist/app.js`: каталог объектов, палитры, подбор по словам, компоновка, перекраска, генерация SVG и состояние интерфейса.
- `dist/style.css`: адаптивный интерфейс.
- `dist/index.html`: разметка и доступные подписи элементов управления.
- `source-art/figma-sheet.svg`: исходный SVG-лист, полученный из макета.
- `source-art/figma-compositions.svg`: предоставленные примеры композиционных решений.
- `source-art/reference-scale.svg`: дополнительно предоставленный лист эталонных композиций для сравнения масштаба и кадрирования.
- `source-art/bboxes.json` и `source-art/extract.py`: границы элементов и воспроизводимое выделение объектов из плоского листа.
- `tests/smoke.mjs`: проверка основных сценариев в браузере и структуры экспортированного SVG.
- `tests/multi-audit.mjs`: визуальная проверка двенадцати наборов из 3–6 предметов в трёх форматах.
- `tests/build-shape-masks.mjs`: воспроизводимое построение масок из SVG-ресурсов.
- `tests/core-check.mjs`: проверка логики композиции и подготовка трёх примеров без внешних зависимостей.
- `examples/`: три экспортированных редактируемых SVG в квадратном, широком и вертикальном форматах.

Исходный лист экспортирован как плоский SVG без смысловых групп. Скрипт `extract.py` выбирает исходные контуры по областям листа, сохраняет нужные `clipPath` и записывает их в каталог объектов. У каждого объекта есть стабильный `id`, название, тип (`main` или `background`) и две версии разной детализации. Названия и смысловые темы для подбора хранятся в `briefAliases` и `briefConcepts`. Выбор детализации загружает соответствующую версию независимо от формата холста.

Палитра описывает исходные цвета Figma и их замены. Загружаемая JSON-палитра содержит название `name` и цвета `bg`, `bg2`, `a`, `b`, `c` в формате `#RRGGBB`; необязательный `d` задаёт светлую деталь. Пример файла находится в `source-art/palette-example.json`. Перекраска меняет токены непосредственно в SVG-контурах; чёрные линии и белые детали сохраняются. Цвета фона используются только в фоне и объектах, а цвета только для объектов не попадают в фон. Фоновые объекты остаются монохромными. Холст содержит лишь цветную подложку: декоративные линии и фигуры не создаются, чтобы результат состоял из исходных иллюстраций. Генератор создаёт SVG без растровых изображений, внешних ссылок и шрифтов: фон и каждый предмет находятся в отдельных группах. Для `clipPath` создаются уникальные идентификаторы, чтобы детали разных экземпляров не конфликтовали.

Компоновка опирается на предоставленные примеры: крупный ведущий объект, предметы второго плана, акценты фона и намеренное кадрирование краями холста. Шесть сочетаний предметов из референса имеют отдельные правила для квадратного, широкого и вертикального кадров. У этих сочетаний первый вариант ближе к образцу по масштабу, расположению, перекрытию и цветовым акцентам; остальные два меняют кадрирование всей группы, сохраняя взаимные пропорции предметов. Для остальных наборов из 2–3 предметов используются прежние схемы расположения и масштаба.

Для сцены с книгой, лампой и фоновыми цветами, а также для наборов из 4–6 предметов с книгой и телефоном, наушниками и цветами либо телефоном и пазлом используются композиционные схемы по примерам. Добавлены схемы для бумажных предметов с телефоном, ежедневника с фоновой лампой, пазла с фоновой книгой и телефона на фоне книги и цветов. Схема задаёт отношения между главными предметами и места для дополнительных акцентов. В сцене с книгой и лампой их корпуса располагаются по примеру предметной сцены; оценка вариантов отдельно штрафует перекрытие страниц книги основанием лампы. Для остальных наборов из 4–6 предметов позиции рассчитываются как связанная группа: второй главный предмет располагается у ведущего, остальные привязываются к этой паре, а фоновые объекты размещаются позади неё. В сцене с наушниками ежедневник и монета размещаются рядом с ведущим предметом; один из вариантов переносит ежедневник ниже. Вертикальный формат использует отдельное расположение по высоте. Масштаб группы задаётся ведущим объектом и форматом кадра по эталонным примерам: допускается осмысленное обрезание краёв вместо уменьшения всей сцены. Каждый объект получает один и тот же коэффициент масштаба. Для 7–12 предметов используется более плотная сетка, при большем количестве главные предметы занимают центральные позиции, а фоновые располагаются ближе к краям. Из восемнадцати кандидатов сервис выбирает три по видимости основных частей предметов, балансу кадра, близости, пересечениям и различию между предложенными вариантами. Отбор происходит по общему качеству кадра с проверкой расстояния между вариантами: слабый или почти повторяющийся кадр не получает отдельное место в тройке. Повторное создание меняет расположение предметов, сохраняя исходные векторные контуры. Жёсткого ограничения количества объектов нет.

Для автоматических схем масштаб зависит от ведущего предмета и формата кадра. Он остаётся одинаковым между тремя вариантами, после повторной генерации и при добавлении предметов к той же сцене с тем же ведущим объектом. Ручная поправка масштаба действует на все предметы выбранного варианта одновременно.

Маленькие монета и карандаш размещаются около основной группы, а фоновые объекты стараются не перекрывать их. Оценка вариантов штрафует чрезмерно удалённые главные предметы и отдельно проверяет связность всей группы, чтобы две самостоятельные пары не оказались далеко друг от друга. Для 4 и более предметов дополнительные главные объекты уточняют своё положение в небольшом диапазоне вокруг схемы: поиск сравнивает видимость и пересечение реальных силуэтов, а ведущая пара остаётся на месте. Маски получены из исходных SVG в сетке 32 × 32; в сам экспорт они не включаются.

Ручные правки хранятся как смещение `dx/dy` и угол `angle` у каждого экземпляра, а общий коэффициент масштаба — в `sceneScale` для комбинации формата, детализации и варианта. Фиксация масштаба хранится в `scaleLocks` для варианта, фиксация поворота — в `rotationLocks` для конкретного экземпляра. Копии имеют собственные идентификаторы; порядок наложения хранится в `layerOrder`. Перетаскивание работает в координатах SVG и не меняет исходные векторные контуры. Пунктирная рамка сохраняет размеры объекта при переносе и обрезается самим холстом; маркеры масштаба и поворота располагаются в видимой части холста. Экспорт включает выбранный вариант, его правки и порядок слоёв, но не элементы редактора.

Подбор по описанию намеренно детерминированный: он сопоставляет названия объектов и смысловые темы (например, учёба, идеи, финансы, работа, уют, музыка), при необходимости выбирая фоновую версию предмета. Явно названные объекты сохраняются в составе сцены; тематические подсказки дополняют набор. Если тема не распознана, сервис просит уточнить описание и не подставляет случайные предметы. Подбор воспроизводим и не требует внешнего API. Новый объект добавляется в `objects` вместе с векторным ресурсом и нужными словами в `briefAliases` или `briefConcepts`; схемы размещения находятся в `sceneSchemas`, цветовые схемы — в `palettes`.

## Ограничения

Подбор по описанию основан на словаре смысловых тем, поэтому неизвестную метафору потребуется уточнить. Для насыщенных сцен из многих предметов можно вручную поправить кадрирование после автоматической раскладки.

## Проверка

`npm test` без установки зависимостей проверяет синтаксис, копирование, поворот, общий масштаб, загруженную палитру и векторный экспорт. Для проверки поведения интерфейса установите Playwright (`npm install`) и браузер (`npx playwright install chromium`), затем запустите `npm run test:browser`. Можно указать системный браузер через переменную `BROWSER_EXECUTABLE`. Браузерные сценарии дополнительно проверяют три варианта, выбор и перенос объекта, порядок слоёв, сохранение проекта, форматы, детализацию и подбор по описанию.

## Примеры результата

- `examples/01-ideas-square.svg`: квадрат, тема идей, телефон и пазл, лавандовая палитра.
- `examples/02-reading-wide.svg`: широкий кадр, книга и телефон, абрикосовая палитра.
- `examples/03-music-portrait.svg`: вертикальный кадр, наушники и фоновые цветы, мятная палитра, версия S.
